# Decisões Arquiteturais

| Decisão | Estado | Justificativa |
| --- | --- | --- |
| Hexagonal pragmática | Aprovada | Isolar detalhes quando houver fronteiras reais. |
| DDD leve e domínio rico | Aprovada | Proteger regras sem sobreengenharia. |
| Records para Value Objects/DTOs imutáveis | Aprovada | Imutabilidade e igualdade por valor. |
| Lombok seletivo | Aprovada | Reduzir repetição sem ocultar modelagem. |
| MapStruct por necessidade | Aprovada | Usar apenas em mapeamentos estruturais repetitivos. |
| Pacotes e ports concretos | Adiado | Dependem de casos de uso reais. |
