Cada wave futura requer escopo, gate, testes proporcionais ao risco, documentação ajustada e PR própria. Testes PostgreSQL descartáveis cobrem migrations e SQL dos fluxos atuais; mudanças futuras ainda requerem validação PostgreSQL proporcional, inclusive de índices e concorrência quando aplicável. A ordem entre módulos independentes pode mudar após requisitos, mas titularidade e segurança precisam ser resolvidas antes de atribuir produção ou eventos a uma fazenda histórica.
