# Domínio BoviGestor

Este vocabulário é inicial e provisório; não define regras não modeladas.

- **Bovine**: entidade conceitual para um bovino, independentemente de sexo ou idade.
- **BovineId**: identidade técnica estável de um bovino.
- **Associação de raça** e **identificação da fazenda** são conceitos distintos.
- Há necessidade futura de registrar histórico temporal de propriedade.

Invariantes, estados reprodutivos, movimentações, tabelas e fluxos permanecem sujeitos a exercícios e decisões futuras.
