# Handoff de Agente

Use este modelo ao transferir continuidade. Um novo chat não constitui aprovação.

```text
Project / task / phase:
Repository / branch / HEAD SHA:
Authorized objective and scope:
Changes performed:
Commands, tests, and results:
Architecture decisions:
Pending work and risks:
Last formal gate and evidence:
Next gate requested:
Communication capability verified / unverified:
```

Quando não houver integração comprovada entre agentes ou chats, produza este relatório e aguarde um canal válido; não simule automação de comunicação.
